# Schat - 多设备聊天系统

![License](https://img.shields.io/badge/License-GPLv3-blue.svg)

Schat 是一个基于 Android 设备的跨设备聊天系统，集成了实时消息传递、用户管理、班级管理等功能。系统采用前端-后端分离架构，通过 ADB 实现设备间的通信与数据同步。

## 📋 项目概述

Schat 是为学校班级环境设计的即时通讯应用，支持多班级、多用户的消息同步。系统包含以下核心功能：

- **用户管理**：账户注册、登录、注销
- **聊天功能**：一对一消息发送与接收，消息持久化存储
- **班级管理**：班级列表管理，班级用户查询
- **设备通信**：通过 ADB 实现设备间的消息同步
- **自动化脚本**：后台日志监控与数据处理

#### 业务脚本

| 脚本 | 功能 | 说明 |
|------|------|------|
| `1.sh` | 日志监控 | 捕获"识别成功"关键词，保存日志 |
| `2.sh` | 日志处理 | 从日志文件中提取姓名 |
| `3.sh` | 名字匹配 | 验证姓名是否在用户列表中 |
| `4.sh` | 用户登录 | 设置当前登录用户，启动应用 |
| `5.sh` | 用户注销 | 恢复应用状态，清除登录信息 |
| `6.sh` | 用户注册 | 注册新用户，创建用户目录 |
| `7.sh` | 创建聊天目录 | 创建消息存储目录 |
| `8.sh` | 创建双向目录 | 本地和远程同时创建聊天目录 |
| `9.sh` | 保存远程消息 | 将接收到的消息保存到本地 |
| `10.sh` | 发送消息 | 发送消息到远程设备 |
| `11.sh` | 班级检索 | 查询班级列表和对应 IP |
| `12.sh` | 用户列表 | 获取远程设备的用户列表 |
| `13.sh` | 设备连接 | 初始化远程设备连接 |
| `14.sh` | 同步用户 | 将用户列表同步到所有设备 |
| `15.sh` | 停止服务 | 优雅停止所有后台脚本 |
| `16.sh` | 数据库检索 | 从班牌数据库中批量查询用户头像 URL（本地） |
| `16.sh` | 数据库检索 | 从班牌数据库中批量查询用户头16L（本地） |
| `17.sh` | 远程检索 | 通过 ADB 调用远程设备的 16.sh 批量查询头像 |
16支持两种模式
**16.sh 16模式**
- 单个查询：`16h "张...`
- 批量查询：`16.sh "张三|李四|王五"` → 输出：`张三:https://...\n李四:https://...\n王五:`

**17.sh 支持两种模式**：
- 单个查询：`17.sh "192.168.1.100:5555" "张三"`
- 批量查询：`17.sh "192.168.1.100:5555" "张三|李四|王五"`

## 🎯 核心功能详解

### 1. 用户认证系统

**注册流程**：
```
用户输入中文姓名 → 验证是否为2-4个汉字 → 创建用户目录 → 添加到用户列表
```

**登录流程**：
```
日志监控捕获识别成功 → 提取用户姓名 → 验证用户存在 → 启动应用 → 设置当前用户
```

**登出流程**：
```
清除当前用户标记 → 恢复应用状态 → 删除临时文件

### 2. 消息系统

**消息格式**：
```
发言人:消息类型:消息内容

示例：
- 张三:0:你好，今天天气真好
- 李四:1:[图片消息]（类型 1 表示图片）
```

**消息存储**：
```
/sdcard/schat/当前用户/班级名/对方用户/时间戳.txt

例如：
/sdcard/schat/张三/一班/李四/1622548800123.txt
```

**消息发送流程**：
```
本地保存消息 → 获取对方设备 IP → 远程设备创建目录 → 远程保存消息
如果远程失败 → 回滚删除本地消息
```

### 3. 班级管理

班级配置文件格式（`/sdcard/schat/devicesIP`）：
```
班级名:IP地址:端口号
一班:192.168.1.100:5555
二班:192.168.1.101:5555
三班:192.168.1.102:5555
```

用户列表文件格式（`/sdcard/schat/USER`）：
```
张三
李四
王五
赵六
```

### 4. 设备通信

- **通信协议**：基于 ADB（Android Debug Bridge）
- **连接方式**：TCP/IP 无线连接
- **数据传输**：通过脚本调用实现文件级消息同步
- **自动重连**：支持心跳检测和自动重启

## 🚀 使用指南

### 安装部署

1. **复制脚本到设备**：
   ```bash
   adb push . /data/local/tmp/schat/
   ```

2. **设置权限**：
   ```bash
   adb shell chmod +x /data/local/tmp/schat/*.sh
   ```

3. **启动脚本**：
   ```bash
   adb shell /system/bin/sh /data/local/tmp/schat/1.sh &
   adb shell /system/bin/sh /data/local/tmp/schat/2.sh &
   adb shell /system/bin/sh /data/local/tmp/schat/3.sh &

## 📝 消息流示例

### 发送消息流程

```
用户输入消息
    ↓
validateInput() - 验证内容非空
    ↓
sendTextMessage() - JavaScript 调用脚本
    ↓
root_cmd(10.sh) - 执行发送脚本
    ↓
[1] 本地保存: /sdcard/schat/张三/一班/李四/时间戳.txt
    ↓
[2] 获取对方 IP: 从 devicesIP 查询
    ↓
[3] 远程执行: adb -s IP shell "7.sh 李四 一班 张三"
    ↓
成功 → 更新 UI 显示时间戳
失败 → 回滚删除本地消息，显示错误提示
```

### 接收消息流程

```
对方设备保存消息到本主控设备
    ↓
loadMessages() 读取本地目录
    ↓
获取所有 *.txt 文件（按时间戳排序）
    ↓
parseMessageFile() 解析消息格式
    ↓
formatTimestamp() 格式化时间
    ↓
渲染消息气泡 UI
```

### 用户头像获取流程（分布式架构）

```
如: 主页聊天列表需要显示"李四"的头像

getAvatarUrl("李四", "192.168.1.100:5555")
    ↓
检查 avatarCache["李四@IP"] 缓存
    ↓
    ├─ 缓存命中 → 直接返回 URL（⚡ 快）
    └─ 缓存未命中 ↓
      16
[第1步] 尝试本地数据库（本设备的 16.sh）
    ↓16
root_cmd("sh /data/local/tmp/schat/16.sh \"李四\"")
    ↓
    ├─ 成功找到 → 缓存并返回 URL ✓
    └─ 失败或无结果 ↓

[第2步] 尝试远程数据库（其他班级设备）
    ↓
root_cmd("sh /data/local/tmp/schat/17.sh \"192.168.1.100:5555\" \"李四\"")
    ↓
    adb connect "192.168.1.100:5555"16
    adb -s "192.168.1.100:5555" shell "sh /data/local/tmp/schat/16.sh \"李四\""
    ↓
    ├─ 成功找到 → 缓存并返回 URL ✓
    └─ 仍失败 → 返回 null，使用首字母备选

页面渲染：
    ├─ URL 有效 → <img src="URL" ...> 显示真实头像
    └─ URL 为 null → 显示首字母圆形
```

**关键特点**：
- ✅ **本地优先**：减少网络调用
- ✅ **远程回源**：支持其他班级用户头像获取
- ✅ **缓存机制**：同一用户只查询一次
- ✅ **优雅降级**：头像失败时使用首字母

### 批量头像获取优化（高效分布式架构）

为了避免为每个用户都发起一次远程调用，系统实现了**智能批量查询**和**按 IP 分组合并**：

#### 核心优化

**1. 批量查询（一次请求多个用户）**：
```
传统方式（低效）：16
  getAvatarUrl("张三") → 调用 16h
  getAvatarUrl("李四") → 调用 16h
  getAvatarUrl("王五") → 调用 16.sh
  总计：3 次调用 ❌

优化方式（高效）：
  batchAvatarRequest([
    {name: "张三", ip: "192.168.1.100:5555"},
    {name: "李四", ip: "192.168.1.100:5555"},
    {name: "王五", ip: "192.168.1.100:5555"}
  ])16
  → 调用 16.sh "张三|李四|王五"
  总计：1 次调用 ✨
```

**2. 按 IP 分组合并**：
```
场景：添加对话时
  所有用户来自同一班级（同一支撑设备）
  → 所有用户一起查询
  → 1 次 ADB 请求
  
场景：主页聊天列表
  多班级对话（来自不同设备）
  → 按 IP 分组
  → 一班用户 → 1 次请求
  → 二班用户 → 1 次请求
  → 总计 2 次请求（而非 N 次）
```

**3. UI 改进（按班级分组显示）**

主页现在展示如下结构：
```
┌─────────────────┐
│    一班         │  ← 班级分组标题
├─────────────────┤
│ 👤 张三         │
│    最后一条消息 │
├─────────────────┤
│ 👤 李四         │
│    最后一条消息 │
├─────────────────┤
│    二班         │  ← 班级分组标题
├─────────────────┤
│ 👤 王五         │
│    最后一条消息 │
└─────────────────┘
```

## 🐛 故障排查

### 常见问题

1. **消息发送失败**
   - 检查是否登录（`cat /sdcard/schat/usernow`）
   - 检查班级 IP 配置（`cat /sdcard/schat/devicesIP`）
   - 检查远程设备连接（`adb devices`）

2. **用户列表为空**
   - 检查 USER 文件是否存在（`ls -l /sdcard/schat/USER`）
   - 检查远程设备是否在线
   - 执行同步命令：`sh 14.sh`

3. **头像显示为首字母（获取失败）**
   - 检查本地数据库是否存在：`ls -l /sdcard/schat/czhl.db`
   - 检查远程设备连接：`adb16ice
   - 手动测试本地查询：`sh 16.sh "<用户名>"`
   - 手动测试远程查询：`sh 17.sh "192.168.1.100:5555" "<用户名>"`
   - 检查缓存（浏览器控制台）：`avatarCache` 对象

4. **脚本停止运行**
   - 查看停止标志：`ls -l /data/local/tmp/schat/stop_all`
   - 检查进程：`ps | grep schat`
   - 查看日志：`adb logcat | grep Schat`
